# pairwise-vehicle-suspension

越野车压过连续减速带，车身还在弹，轮子已经悬空，落地瞬间又穿进地面：悬挂按固定弹簧系数，质量变化和载荷没有参与；轮胎碰撞只做单点射线，路缘石边缘漏检；前后轴阻尼共用一套参数，点头和甩尾同时出现；四驱扭矩分配按固定比例，单轮打滑时另一轴空转；悬挂行程到极限没有硬限位，轮胎穿进轮拱；车身刚体和悬挂子步不同步，高速过坎时能量注入；网络同步只发车身位置，客户端轮子各自弹；不同路面材质的摩擦系数没进轮胎模型，冰面和柏油一样；刹车时重心转移没耦合到悬挂，后轮抱死；悬挂包围盒没更新，摄像机近裁剪穿车；载具在斜坡上驻车，手刹只锁后轮，车缓慢下滑；轮胎温度/磨损影响抓地，长时间比赛后圈速突变；悬挂参数在画质档位间共享，低画质物理变软。physics/vehicle_suspension.py 是核心，tests/test_vehicle_suspension.py 15个红。要修的是：载荷弹簧；多点轮胎；前后轴分离；扭矩分配；行程限位；子步同步；网络轮态；路面摩擦；重心转移；包围盒；驻车制动；磨损抓地；画质隔离。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
